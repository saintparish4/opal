  1. Sep 19, 2026

    Opal v0.3.0 Release

    Opal now installs the versions npm would: on a Next.js scaffold, 432 of npm's 433 package versions match. Linking runs in parallel, about 2.7× faster than v0.2.1, and an install names every package whose install scripts it didn't run.

    Sharif

  2. Aug 29, 2026

    Opal v0.2.1 Release

    A performance fix for one finding: a 367-package Next.js install spent most of its time parsing package metadata it never used. Version bodies are now parsed on demand, which took an offline install from 128.6s to 37.7s.

    Sharif

  3. Aug 29, 2026

    Opal v0.2.0 Release

    Correctness, speed, and visibility across the package manager. Four bugs fixed here produced a wrong node_modules without ever failing an install. opal.lock is now v3.

    Sharif
